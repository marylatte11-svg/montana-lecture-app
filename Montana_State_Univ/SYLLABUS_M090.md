## 1. 📌 COURSE DESCRIPTION & GOALS

M090 Introductory Algebra is designed to build foundational algebraic literacy and mathematical confidence for students preparing for college-level quantitative coursework (such as M105 Contemporary Mathematics or M121 College Algebra). 

This course focuses on conceptual understanding, operational fluency, and real-world mathematical modeling. Students will develop problem-solving strategies using linear expressions, linear equations and inequalities, systems and graphing in the Cartesian coordinate plane, function notation, and introductory quadratic functions. 

Special emphasis is placed on overcoming **math anxiety** through structured, step-by-step thinking ("One Problem = One Slide"), explicit visualization with LaTeX typography, and interactive Professor-TA guided problem breakdowns.

---

## 2. 🎯 STUDENT LEARNING OUTCOMES (SLOs)

Upon successful completion of M090, students will be able to:
1. **Arithmetic & Algebraic Fluency:** Perform operations on signed real numbers, simplify polynomial expressions using exponent properties and the distributive law, and evaluate algebraic expressions correctly with order of operations (PEMDAS).
2. **Linear Equations & Inequalities:** Solve one-variable multi-step linear equations, equations containing fractions (clearing denominators using LCD), literal formulas, and linear inequalities expressing solutions in interval notation.
3. **Graphing & Coordinate Geometry:** Plot points and parent functions in the Cartesian plane, calculate and interpret slope as an average rate of change, write equations of lines in slope-intercept and point-slope forms, and graph linear equations using intercepts.
4. **Function Literacy:** Distinguish between relations and functions using algebraic and graphical definitions (Vertical Line Test), evaluate functions using $f(x)$ notation, and interpret mathematical models in everyday context (e.g., Bozeman elevation vs. boiling point, commission models).
5. **Quadratic Foundations:** Identify characteristics of parabolas (vertex, axis of symmetry, intercepts), and solve quadratic equations using multiple strategic methods: the Square Root Property, Greatest Common Factor (GCF), Trinomial Factoring, and the Quadratic Formula.
