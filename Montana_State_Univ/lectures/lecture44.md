## Slide 1: Section 3.7: Graphing Quadratic Functions

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 (Workbook p. 87)

### Problem
**5-Point Graphing Method for \(f(x) = ax^2 + bx + c\):**

1. **Find the Vertex** — \(x = \dfrac{-b}{2a}\), then compute \(y\)
2. **Find the y-intercept** — \((0, c)\)
3. **Find the x-intercept(s)** — Set \(f(x)=0\), solve
4. **Symmetric Point** — Mirror the y-intercept across axis of symmetry
5. **Connect** — Draw a smooth U-shaped curve through all points

**State Domain and Range:**
- Domain: Always \((-\infty, \infty)\)
- Range: \([k, \infty)\) if \(a>0\) or \((-\infty, k]\) if \(a<0\) (\(k\) = vertex y-value)

### Solution
**Remember:**
- \(a > 0\) → Parabola opens **upward** (minimum at vertex)
- \(a < 0\) → Parabola opens **downward** (maximum at vertex)
- Axis of symmetry: \(x = \dfrac{-b}{2a}\) (always passes through vertex)

### Key Note
**Sora’s Tip:** The symmetric point of the y-intercept \((0,c)\) is at \\(\left(\dfrac{-b}{a},\,c\right)\\). Just double the x-distance from the axis!

[TA Sora] Five steps! And after five steps we have a perfect parabola. Let’s practice on four examples from the workbook.

## Slide 2: Graph \( g(x) = x^2 + 6x + 5 \) Using Vertex and Table

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 1 (Workbook p. 87)

### Problem
**Graph \(g(x) = x^2 + 6x + 5\)**

**Step 1 — Vertex:** \(x = \dfrac{-6}{2(1)} = -3\),\quad \(g(-3) = 9-18+5 = -4\)

**Vertex:** \((-3,\,-4)\)

**Step 2 — Table** (centered at vertex x=-3):

| \(x\) | \(g(x)\) |
|---|---|
| \(-5\) | \(25-30+5=0\) |
| \(-4\) | \(16-24+5=-3\) |
| \(-3\) | \(-4\) (vertex) |
| \(-2\) | \(4-12+5=-3\) |
| \(-1\) | \(1-6+5=0\) |

### Solution
**x-intercepts:** \((-5,0)\) and \((-1,0)\)

**Verification by factoring:** \(x^2+6x+5 = (x+5)(x+1)\) → \(x=-5\) or \(x=-1\) ✓

**y-intercept:** \(g(0) = 5\) → \((0,\,5)\)

**Domain:** \((-\infty, \infty)\)
**Range:** \([-4, \infty)\) since \(a=1>0\) (minimum is \(-4\))

### Key Note
**Sora’s Note:** The table is symmetric around x=-3. Notice g(-4)=g(-2)=-3 and g(-5)=g(-1)=0. This confirms symmetry!

### Script
[Prof. Park] Example 1: g(x) = x²+6x+5. Vertex at (-3,-4). Build the table with two points on each side.

[TA Sora] I love how the table is perfectly symmetric! Both sides mirror each other. That’s how you know the parabola is graphed correctly.

## Slide 3: Graph \( h(x) = -2x^2 + 4x + 6 \) Using All Key Points

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 2 (Workbook p. 87)

### Problem
**Graph \(h(x) = -2x^2 + 4x + 6\)**

**Step 1 — Vertex:** \(a=-2,\;b=4,\;c=6\)
$$x = \dfrac{-4}{2(-2)} = \dfrac{-4}{-4} = 1,\quad h(1) = -2+4+6 = 8$$

**Vertex:** \((1,\,8)\) — Maximum!

**Step 2 — y-intercept:** \(h(0) = 6\) → \((0,\,6)\)

**Step 3 — x-intercepts:** Set \(h(x)=0\)
$$-2x^2+4x+6=0 \Rightarrow x^2-2x-3=0 \Rightarrow (x-3)(x+1)=0$$

### Solution
$$x = 3 \quad \text{or} \quad x = -1$$

**x-intercepts:** \((-1,\,0)\) and \((3,\,0)\)

**Symmetric point** of y-intercept: Mirror \((0,6)\) across \(x=1\) → \((2,\,6)\)

**Five key points:**
\((-1,0)\), \((0,6)\), \((1,8)\), \((2,6)\), \((3,0)\)

**Domain:** \((-\infty, \infty)\)

**Range:** \((-\infty, 8]\) since \(a=-2<0\) (maximum is \(8\))

### Key Note
**Sora’s Step:** Divide by -2 first: \(-2x^2+4x+6=0 \Rightarrow x^2-2x-3=0\). This makes factoring much easier!

### Script
[Prof. Park] h(x) opens downward since a=-2. The vertex (1,8) is the MAXIMUM. Range is all y-values less than or equal to 8.

[TA Sora] And dividing by -2 before factoring is so smart! We get x²-2x-3=0 which factors to (x-3)(x+1). Clean roots!

## Slide 4: Graph \( g(x) = 2x^2 - 8x \)

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 3 (Workbook p. 88)

### Problem
**Graph \(g(x) = 2x^2 - 8x\)**

**Step 1 — Vertex:** \(a=2,\;b=-8,\;c=0\)
$$x = \dfrac{-(-8)}{2(2)} = \dfrac{8}{4} = 2,\quad g(2) = 2(4)-8(2) = 8-16 = -8$$

**Vertex:** \((2,\,-8)\) — Minimum!

**Step 2 — x-intercepts:** Factor GCF (no constant term!)
$$2x^2-8x=0 \Rightarrow 2x(x-4)=0 \Rightarrow x=0 \text{ or } x=4$$

### Solution
**x-intercepts:** \((0,\,0)\) and \((4,\,0)\)

**y-intercept:** \(g(0)=0\) → \((0,\,0)\) — Same as one x-intercept!

**Additional point** using table:
$$g(1) = 2-8 = -6 \rightarrow (1,-6)$$
$$g(3) = 18-24 = -6 \rightarrow (3,-6) \text{ (symmetric)}$$

**Five key points:** \((0,0)\), \((1,-6)\), \((2,-8)\), \((3,-6)\), \((4,0)\)

**Domain:** \((-\infty, \infty)\)

**Range:** \([-8, \infty)\)

### Key Note
**Sora’s Note:** The origin \((0,0)\) is BOTH an x-intercept and the y-intercept. Use extra table points like \((1,-6)\) to plot the curve accurately.

### Script
[Prof. Park] g(x)=2x²-8x has no constant term, so GCF factoring gives us 2x(x-4)=0. Quick and easy!

[TA Sora] The vertex is at (2,-8), the minimum. The parabola goes down to -8 and then back up. Domain is all real numbers, range is [-8, infinity).

## Slide 5: Graph \( f(x) = -\frac{1}{2}(x+1)^2 + 8 \) (Vertex Form)

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 4 (Workbook p. 88)

### Problem
**Graph \(f(x) = -\dfrac{1}{2}(x+1)^2 + 8\)**

**Vertex form:** \(f(x) = a(x-h)^2 + k\)

**Read directly:**
- \(a = -\dfrac{1}{2}\) (opens downward, wide)
- \(h = -1\) (vertex x-coordinate)
- \(k = 8\) (vertex y-coordinate)

**Vertex:** \((-1,\,8)\) — Maximum!

**Step 2 — y-intercept:** \(f(0) = -\dfrac{1}{2}(1)+8 = -0.5+8 = 7.5\)

### Solution
**x-intercepts:** Set \(f(x)=0\):
$$-\dfrac{1}{2}(x+1)^2 + 8 = 0$$
$$(x+1)^2 = 16 \Rightarrow x+1 = \pm 4$$
$$x = 3 \quad \text{or} \quad x = -5$$

**x-intercepts:** \((-5,\,0)\) and \((3,\,0)\)

**Symmetric point** of \((0,7.5)\) across \(x=-1\): \((-2,\,7.5)\)

**Five key points:** \((-5,0)\), \((-2,7.5)\), \((-1,8)\), \((0,7.5)\), \((3,0)\)

**Domain:** \((-\infty, \infty)\)

**Range:** \((-\infty, 8]\)

### Key Note
**Sora’s Tip:** Multiply both sides by \(-2\) to isolate \((x+1)^2\): \(-\frac{1}{2}(x+1)^2 = -8 \Rightarrow (x+1)^2 = 16\).

### Script
[Prof. Park] Vertex form is the most elegant way to graph. Just read h, k directly, and the vertex is instantly known.

[TA Sora] And with a=-1/2, the parabola opens down and is wider than usual! The coefficient magnitude being less than 1 means it spreads out more.

## Slide 6: Evaluating Two Functions: \( f(x) = x^2-6x+4 \) and \( g(x) = -2x+25 \)

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 5 (Workbook p. 89)

### Problem
**Given \(f(x) = x^2 - 6x + 4\) and \(g(x) = -2x + 25\), find:**

**A.** \(f(-7)\)

**B.** \(g(-7)\)

### Solution
**A.** \(f(-7) = (-7)^2 - 6(-7) + 4 = 49 + 42 + 4 = \mathbf{95}\)

**B.** \(g(-7) = -2(-7) + 25 = 14 + 25 = \mathbf{39}\)

**Observation:** Both functions take the input \(-7\).
- \(f\) is quadratic: its value \(95\) is much larger due to the \(x^2\) term.
- \(g\) is linear: its value \(39\) grows more slowly.

### Key Note
**Sora’s Sign Check:** \((-7)^2 = 49\) (positive!) and \(-6(-7) = +42\) (two negatives!). Be careful with signs when input is negative.

### Script
[Prof. Park] Example 5 introduces TWO functions simultaneously. We evaluate each at the same x-value and compare.

[TA Sora] f(-7) = 49+42+4 = 95 and g(-7) = 14+25 = 39. The quadratic grows so much faster than the linear function!

## Slide 7: Function Composition: \( f(x+5) \) and \( g(x+5) \)

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 5 (Workbook p. 89)

### Problem
**Given \(f(x) = x^2-6x+4\) and \(g(x) = -2x+25\), find:**

**C.** \(f(x+5)\)

**D.** \(g(x+5)\)

### Solution
**C.** \(f(x+5)\): Replace every \(x\) with \((x+5)\)
$$f(x+5) = (x+5)^2 - 6(x+5) + 4$$
$$= x^2+10x+25 - 6x-30 + 4$$
$$= \mathbf{x^2 + 4x - 1}$$

**D.** \(g(x+5)\): Replace every \(x\) with \((x+5)\)
$$g(x+5) = -2(x+5) + 25 = -2x-10+25 = \mathbf{-2x + 15}$$

### Key Note
**Sora’s FOIL Reminder:** \((x+5)^2 = x^2 + 10x + 25\), NOT \(x^2+25\)! Always expand the binomial squared fully.

### Script
[Prof. Park] Parts C and D test function composition. Replace every x with the expression (x+5).

[TA Sora] For g(x+5) it’s simple: just replace x with x+5 in the linear function. For f(x+5) we need FOIL for the squared binomial.

## Slide 8: Solving: \( g(x) = 17 \) and \( f(x) = g(x) \)

**Subtitle:** Unit 3 • Lecture 44 • Section 3.7 Example 5 (Workbook p. 89)

### Problem
**Given \(f(x) = x^2-6x+4\) and \(g(x) = -2x+25\), find:**

**E.** Solve for \(x\) if \(g(x) = 17\)

**F.** Solve for \(x\) if \(f(x) = g(x)\)

### Solution
**E.** \(g(x) = 17\):
$$-2x+25 = 17 \Rightarrow -2x = -8 \Rightarrow x = \mathbf{4}$$

**F.** \(f(x) = g(x)\): Set the two functions equal
$$x^2-6x+4 = -2x+25$$
$$x^2-6x+2x+4-25 = 0$$
$$x^2-4x-21 = 0$$
$$(x-7)(x+3) = 0$$
$$x = \mathbf{7} \quad \text{or} \quad x = \mathbf{-3}$$

**Intersection points:** At \(x=7\): \(g(7)=-14+25=11\) → \((7,11)\)
At \(x=-3\): \(g(-3)=6+25=31\) → \((-3,31)\)

### Key Note
**Sora’s Note for Part F:** Setting f(x)=g(x) finds where the parabola and line INTERSECT. Rearrange to one side = 0, then factor or use the Quadratic Formula.

### Script
[Prof. Park] Part F is a beautiful application: where do the parabola and the line cross? Setting f(x)=g(x) and solving gives the intersection points.

[TA Sora] x²-6x+4 = -2x+25 becomes x²-4x-21=0. Factoring gives (x-7)(x+3)=0. Two intersection points at x=7 and x=-3!
