## Slide 1: Section 3.3: Finding Intercepts by Factoring

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 (Workbook p. 71)

### Problem
### The Power of Factoring (Workbook p. 71)
When a quadratic function has all three terms ($ax^2 + bx + c$), we set $f(x) = 0$:
$$\mathbf{ax^2 + bx + c = 0}$$
- If the trinomial can be factored into two binomials:
  $$\mathbf{(x - r_1)(x - r_2) = 0}$$
- We apply the **Zero Product Property** to solve each factor separately!

### Solution
$$\begin{aligned}
\text{Zero Product Property: } & \text{If } A \cdot B = 0, \text{ then } \mathbf{A = 0} \text{ or } \mathbf{B = 0}. \\[0.5em]
(x - 2)(x - 3) = 0 & \implies x - 2 = 0 \implies \mathbf{x = 2} \\
& \text{or } x - 3 = 0 \implies \mathbf{x = 3}
\end{aligned}$$

### Key Note
**Must equal ZERO:** The Zero Product Property ONLY works if the other side equals $0$! If $(x - 2)(x - 3) = 12$, you CANNOT set $x - 2 = 12$!

### Script
[Prof. Park] Welcome to Section 3.3! The Zero Product Property is one of the most powerful theorems in algebra.

[TA Sora] If two numbers multiply to 0, at least one of them MUST be 0! That lets us break a quadratic into two simple linear equations.

## Slide 2: Section 3.3 Example 1: Solving x^2 - 5x + 6 = 0

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 Example 1 (Workbook p. 71)

### Problem
### Example 1 (Workbook p. 71)
Find the $x$-intercepts for $\mathbf{f(x) = x^2 - 5x + 6}$ by factoring:
- Set $x^2 - 5x + 6 = 0$.
- Find two numbers that multiply to $+6$ and add to $-5$.
- Apply the Zero Product Property.

### Solution
$$\begin{aligned}
x^2 - 5x + 6 & = 0 \\[0.5em]
\text{Find factors of } 6 \text{ adding to } -5: & \quad (-2) \cdot (-3) = +6, \quad (-2) + (-3) = -5 \\[0.5em]
(x - 2)(x - 3) & = 0 \\[0.5em]
x - 2 = 0 & \implies \mathbf{x = 2} \\
x - 3 = 0 & \implies \mathbf{x = 3} \\[0.8em]
\mathbf{x\text{-intercepts: }} & \mathbf{(2, 0) \quad \text{and} \quad (3, 0)}
\end{aligned}$$

### Key Note
**Signs flip when solving:** The factors are $(x - 2)$ and $(x - 3)$, but the solutions are $x = +2$ and $x = +3$! Setting each to zero flips the sign.

### Script
[Prof. Park] In Example 1, $-2$ and $-3$ multiply to $+6$ and add to $-5$. The factors are $(x - 2)(x - 3) = 0$.

[TA Sora] Setting each to zero gives $x = 2$ and $x = 3$. The parabola hits the $x$-axis at $(2, 0)$ and $(3, 0)$!

## Slide 3: Section 3.3 Example 2: Intercepts & Vertex for f(x) = x^2 + 7x + 12

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 Example 2 (Workbook p. 71)

### Problem
### Example 2 (Workbook p. 71)
For $\mathbf{f(x) = x^2 + 7x + 12}$:
- **A. Find the $x$-intercept(s) by factoring:** __________________________
- **B. Find the $y$-intercept:** __________________________
- **C. Find the vertex:** __________________________

### Solution
$$\begin{aligned}
\textbf{A. x-intercepts: } & x^2 + 7x + 12 = 0 \\
& (x + 3)(x + 4) = 0 \\
& x + 3 = 0 \implies x = -3, \quad x + 4 = 0 \implies x = -4 \\
& \implies \mathbf{(-3, 0) \quad \text{and} \quad (-4, 0)} \\[0.8em]
\textbf{B. y-intercept: } & f(0) = 12 \implies \mathbf{(0, 12)} \\[0.8em]
\textbf{C. Vertex: } & x_v = -\frac{7}{2(1)} = -3.5, \\
& y_v = (-3.5)^2 + 7(-3.5) + 12 = 12.25 - 24.5 + 12 = \mathbf{-0.25} \\
& \implies \mathbf{(-3.5, -0.25)}
\end{aligned}$$

### Key Note
**Midpoint check:** The vertex $x = -3.5$ is exactly halfway between $-3$ and $-4$! Symmetrical perfection.

### Script
[Prof. Park] In Example 2, $3$ and $4$ multiply to $12$ and add to $7$. So $(x + 3)(x + 4) = 0$.

[TA Sora] The $x$-intercepts are $(-3, 0)$ and $(-4, 0)$. And the vertex sits at $(-3.5, -0.25)$!

## Slide 4: Section 3.3 Example 3: Factoring with GCF: 2x^2 - 8x = 0

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 Example 3 (Workbook p. 72)

### Problem
### Example 3 (Workbook p. 72)
Find the $x$-intercepts for $\mathbf{f(x) = 2x^2 - 8x}$:
- Notice there is no constant term ($c = 0$).
- Factor out the Greatest Common Factor (GCF).
- Apply the Zero Product Property.

### Solution
$$\begin{aligned}
2x^2 - 8x & = 0 \\[0.5em]
2x(x - 4) & = 0 \quad (\text{factor out GCF } 2x) \\[0.5em]
2x = 0 & \implies \mathbf{x = 0} \\
x - 4 = 0 & \implies \mathbf{x = 4} \\[0.8em]
\mathbf{x\text{-intercepts: }} & \mathbf{(0, 0) \quad \text{and} \quad (4, 0)}
\end{aligned}$$

### Key Note
**x = 0 IS A VALID SOLUTION:** When factoring out $2x$, setting $2x = 0$ gives $x = 0$. Never divide by $x$ and lose the root $x = 0$!

### Script
[Prof. Park] In Example 3, factor out the GCF $2x$. That leaves $2x(x - 4) = 0$.

[TA Sora] Setting $2x = 0$ gives $x = 0$, and setting $x - 4 = 0$ gives $x = 4$. One intercept is right at the origin $(0, 0)$!

## Slide 5: Section 3.3 Example 4: Difference of Squares 4x^2 - 25 = 0

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 Example 4 (Workbook p. 72)

### Problem
### Example 4 (Workbook p. 72)
Find the $x$-intercepts for $\mathbf{f(x) = 4x^2 - 25}$:
- Recognize the Difference of Two Squares pattern: $A^2 - B^2 = (A - B)(A + B)$.
- Factor and solve for $x$.

### Solution
$$\begin{aligned}
4x^2 - 25 & = 0 \\[0.5em]
(2x - 5)(2x + 5) & = 0 \\[0.5em]
2x - 5 = 0 & \implies 2x = 5 \implies \mathbf{x = \frac{5}{2} = 2.5} \\
2x + 5 = 0 & \implies 2x = -5 \implies \mathbf{x = -\frac{5}{2} = -2.5} \\[0.8em]
\mathbf{x\text{-intercepts: }} & \mathbf{\left(\frac{5}{2}, 0\right) \quad \text{and} \quad \left(-\frac{5}{2}, 0\right)}
\end{aligned}$$

### Key Note
**Two methods available:** Notice you could also use the Square Root Property here: $4x^2 = 25 \implies x^2 = 25/4 \implies x = \pm 5/2$! Both methods give the exact same result!

### Script
[Prof. Park] In Example 4, $4x^2 - 25$ is a difference of squares: $(2x - 5)(2x + 5) = 0$.

[TA Sora] That gives $x = \pm \frac{5}{2} = \pm 2.5$. Symmetrical across the $y$-axis!

## Slide 6: The 'Must Equal Zero' Trap: x(x - 5) = 6

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 Common Trap

### Problem
### Solve: $x(x - 5) = 6$
- **Fatal Student Error:** Setting $x = 6$ or $x - 5 = 6$! Why is this completely false?
- **Correct Procedure:** Multiply out, subtract 6 to set equation equal to ZERO, and then factor!

### Solution
$$\begin{aligned}
x(x - 5) & = 6 \\[0.5em]
x^2 - 5x & = 6 \quad (\text{distribute}) \\[0.5em]
x^2 - 5x - 6 & = 0 \quad (\text{MUST EQUAL ZERO!}) \\[0.5em]
(x - 6)(x + 1) & = 0 \quad (\text{factor}) \\[0.5em]
\mathbf{x} & = \mathbf{6 \quad \text{or} \quad x = -1}
\end{aligned}$$

### Key Note
**There is no 'Six Product Property':** If $A \cdot B = 6$, $A$ could be $2$ and $B$ could be $3$. Neither has to be $6$! The product property ONLY works for ZERO!

### Script
[Prof. Park] Sora, warn them about this fatal trap.

[TA Sora] There is NO Six Product Property! You must always distribute and bring everything to one side so it equals ZERO before factoring!

## Slide 7: Sora's Protocol for Solving by Factoring

**Subtitle:** Unit 3 • Lecture 38 • Section 3.3 Protocol

### Problem
### Factoring Protocol for Quadratic Equations
1. **Set to zero:** Move all terms to one side: $ax^2 + bx + c = 0$.
2. **Look for a GCF first:** Factor out any common monomial factor.
3. **Count the terms:**
   - **2 terms:** Check for difference of squares ($A^2 - B^2$).
   - **3 terms ($a = 1$):** Find factors of $c$ that add to $b$.
   - **3 terms ($a \neq 1$):** Use the $ac$-method / grouping.
4. **Apply Zero Product Property:** Set each factor equal to zero and solve.

### Solution
$$\begin{array}{|c|c|c|} 
\hline
\textbf{Structure} & \textbf{Method} & \textbf{Example} \\
\hline
2x^2 - 8x = 0 & \text{GCF} & 2x(x - 4) = 0 \\
\hline
x^2 - 25 = 0 & \text{Difference of Squares} & (x - 5)(x + 5) = 0 \\
\hline
x^2 - 5x + 6 = 0 & \text{Trinomial } a = 1 & (x - 2)(x - 3) = 0 \\
\hline
\end{array}$$

### Key Note
**Check your factors:** Always FOIL your binomials back out to verify they match the original trinomial before solving!
