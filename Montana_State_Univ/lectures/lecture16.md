### [Slide 1] The Rectangular (Cartesian) Coordinate System
*Unit 2 • Lecture 16 • Section 2.0 (Workbook p. 30)*

#### 📖 Official Workbook Problem
### The Rectangular (Cartesian) Coordinate Plane (Workbook p. 30)
- **Axes:** The horizontal line is the **$x$-axis**, and the vertical line is the **$y$-axis**.
- **Origin:** The intersection of the two axes at $(0, 0)$.
- **Quadrants:** The axes divide the plane into four quadrants:
  - **Quadrant I:** $(+, +)$
  - **Quadrant II:** $(-, +)$
  - **Quadrant III:** $(- , -)$
  - **Quadrant IV:** $(+, -)$
- **Ordered Pair:** $(x, y)$ where $x$ is horizontal position and $y$ is vertical position.

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Origin: } & (0, 0) \\
\text{Quadrant I: } & x > 0, y > 0 \quad (+, +) \\
\text{Quadrant II: } & x < 0, y > 0 \quad (-, +) \\
\text{Quadrant III: } & x < 0, y < 0 \quad (-, -) \\
\text{Quadrant IV: } & x > 0, y < 0 \quad (+, -)
\end{aligned}$$

#### ⚠️ Pitfall & Strategy
**Ordered Pair Sequence:** Always move horizontally along the $x$-axis first, then vertically along the $y$-axis! $(x, y) \neq (y, x)$.

### [Slide 2] Section 2.0 Example 1A: Plotting Point (4, 0)
*Unit 2 • Lecture 16 • Section 2.0 Example 1A (Workbook p. 30)*

#### 📖 Official Workbook Problem
### Example 1A (Workbook p. 30)
Plot and label the ordered pair on the Cartesian plane:
$$\mathbf{A.\; (4, 0)}$$
- Identify the $x$-coordinate and $y$-coordinate.
- State its location: Does it lie in a quadrant or on an axis?

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Given: } & (x, y) = (4, 0) \\[0.5em]
\text{Step 1: } & \text{Start at the origin } (0, 0). \\
\text{Step 2: } & \text{Move } \mathbf{4 \text{ units right}} \text{ along the } x\text{-axis.} \\
\text{Step 3: } & y = 0 \implies \text{Do not move vertically.} \\[0.5em]
\text{Location: } & \mathbf{\text{On the positive } x\text{-axis (an } x\text{-intercept)}}.
\end{aligned}$$

#### ⚠️ Pitfall & Strategy
**Points with zero coordinates:** If $y = 0$, the point lies directly on the $x$-axis. It does NOT belong to any quadrant!

*Unit 2 • Lecture 16 • Section 2.0 Example 1B (Workbook p. 30)*

#### 📖 Official Workbook Problem
### Example 1B (Workbook p. 30)
Plot and label the ordered pair on the Cartesian plane:
$$\mathbf{B.\; (-1, 3)}$$
- Identify the direction of horizontal and vertical displacement.
- State which quadrant contains this point.

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Given: } & (x, y) = (-1, 3) \\[0.5em]
\text{Step 1: } & \text{Start at the origin } (0, 0). \\
\text{Step 2: } & x = -1 \implies \text{Move } \mathbf{1 \text{ unit left}}. \\
\text{Step 3: } & y = 3 \implies \text{Move } \mathbf{3 \text{ units up}}. \\[0.5em]
\text{Location: } & \mathbf{\text{Quadrant II } (-, +)}.
\end{aligned}$$

#### ⚠️ Pitfall & Strategy
**Sign awareness:** A negative $x$ means move left, while a positive $y$ means move up. That places us in Quadrant II!

$$\mathbf{C.\; (0, 5)}$$
- Identify the $x$-coordinate and $y$-coordinate.
- State its location: Does it lie in a quadrant or on an axis?

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Given: } & (x, y) = (0, 5) \\[0.5em]
\text{Step 1: } & \text{Start at the origin } (0, 0). \\
\text{Step 2: } & x = 0 \implies \text{No horizontal movement.} \\

### [Slide 7] Basic Graphing Strategy: Input (x) & Output (y)
*Unit 2 • Lecture 16 • Section 2.0 Strategy (Workbook p. 30)*

#### 📖 Official Workbook Problem
### Basic Graphing Strategy (Workbook p. 30)
- **Input values ($x$):** The independent variable chosen from the domain.
- **Output values ($y$):** The dependent variable computed from the algebraic expression.
- **Graph:** The set of all ordered pairs $(x, y)$ that satisfy the equation.
- **Rule of Thumb:** Plot enough points to clearly see the geometric trend (straight line, curve, or V-shape)!

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Step 1: } & \text{Choose a convenient set of } x\text{-values (e.g. } -2, -1, 0, 1, 2\text{).} \\
\text{Step 2: } & \text{Substitute each } x \text{ into the equation to calculate } y. \\
\text{Step 3: } & \text{List ordered pairs } (x, y) \text{ in a table of values.} \\
\text{Step 4: } & \text{Plot each point on the coordinate plane.} \\
\text{Step 5: } & \text{Connect the points with a smooth line or curve with arrows.}
\end{aligned}$$

#### ⚠️ Pitfall & Strategy
**Picking convenient numbers:** Choose $x$-values that keep calculations simple, like $0$ and values that cancel out denominators if fractions are involved!

### [Slide 8] Definition: Solution of an Equation in Two Variables
*Unit 2 • Lecture 16 • Section 2.0 Definition (Workbook p. 30)*

#### 📖 Official Workbook Problem
### Definition of a Solution (Workbook p. 30)
An ordered pair $(x, y)$ is a **solution to an equation involving $x$ and $y$** if the equation becomes a **true statement** when the $x$- and $y$-values of the ordered pair are substituted into the equation.

$$\text{If substituted: } \text{Left Side} = \text{Right Side} \implies \text{Solution (Point lies on graph)}$$

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Given equation: } & 2x + y = 7 \\[0.5em]
\text{Test Point } (2, 3): & 2(2) + 3 = 4 + 3 = 7 \implies \mathbf{7 = 7 \; (\text{TRUE! Solution})} \\
\text{Test Point } (1, 4): & 2(1) + 4 = 2 + 4 = 6 \neq 7 \implies \mathbf{6 = 7 \; (\text{FALSE! Not a solution})}
\end{aligned}$$

#### ⚠️ Pitfall & Strategy
**Check both coordinates:** Always put $x$ into the $x$-spot and $y$ into the $y$-spot. Don't swap them!

#### 🎙️ Lecture Dialogue (Prof. Park & TA Sora)
[Prof. Park] This definition is fundamental: a point is a solution if and only if it makes the statement true.

[TA Sora] Visually, that means the point lies directly ON the line or curve!

### [Slide 9] Testing Solutions on the Coordinate Plane: 2x + y = 7
*Unit 2 • Lecture 16 • Section 2.0 Verification (Workbook p. 30)*

#### 📖 Official Workbook Problem
### Testing Points for $2x + y = 7$
Determine algebraically and visually whether the following points are solutions to $2x + y = 7$:
- **Point P:** $(2, 3)$
- **Point Q:** $(4, -1)$
- **Point R:** $(1, 2)$

#### 💡 Complete Step-by-Step Solution
$$\begin{aligned}
\text{Point P } (2, 3): & 2(2) + 3 = 4 + 3 = 7 \implies \mathbf{\text{TRUE } \implies \text{ON LINE}} \\[0.5em]
\text{Point Q } (4, -1): & 2(4) + (-1) = 8 - 1 = 7 \implies \mathbf{\text{TRUE } \implies \text{ON LINE}} \\[0.5em]
\text{Point R } (1, 2): & 2(1) + 2 = 2 + 2 = 4 \neq 7 \implies \mathbf{\text{FALSE } \implies \text{OFF LINE}}
\end{aligned}$$

#### ⚠️ Pitfall & Strategy
**Visual connection:** Notice on the coordinate plane how $(2, 3)$ and $(4, -1)$ sit perfectly on the line $y = -2x + 7$, while $(1, 2)$ is completely off the line!

#### 🎙️ Lecture Dialogue (Prof. Park & TA Sora)
[Prof. Park] Look at the graph. The blue line represents all solutions to $2x + y = 7$.

[TA Sora] Point P $(2, 3)$ and Point Q $(4, -1)$ light up directly on the blue line! Point R $(1, 2)$ misses the line entirely!
