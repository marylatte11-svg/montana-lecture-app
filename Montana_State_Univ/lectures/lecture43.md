## Slide 2: x-Intercepts: \( g(x) = x^2 + 6x \) (Factor GCF)

**Subtitle:** Unit 3 • Lecture 43 • Section 3.6 Example 1A (Workbook p. 83)

### Problem
**Find the x-intercepts of \(g(x) = x^2 + 6x\)**

Set \(g(x) = 0\):
$$x^2 + 6x = 0$$

**Method: Factor out the GCF**
- Both terms share a factor of \(x\)
$$x(x + 6) = 0$$

**Zero-Product Property:**
$$x = 0 \quad \text{or} \quad x+6 = 0$$

### Solution
$$x = 0 \qquad \text{or} \qquad x = -6$$

**x-intercepts:** \((0,\,0)\) and \((-6,\,0)\)

**Note:** The x-intercept \((0,0)\) is also the y-intercept!

**y-intercept:** \(g(0) = 0 + 0 = 0\) → \((0,\,0)\)

**Vertex:** \(x = \dfrac{-6}{2(1)} = -3\),\quad \(g(-3) = 9-18 = -9\)

**Vertex:** \((-3,\,-9)\)

### Key Note
**Sora’s Note:** Never divide both sides by \(x\)! That would make you lose the solution \(x=0\). Always FACTOR instead.

### Script
[TA Sora] g(x) = x²+6x has no constant term, so we factor out x. This gives x(x+6)=0.

[Prof. Park] And by the Zero-Product Property, either x=0 or x+6=0. Two x-intercepts: the origin and (-6,0).

## Slide 3: x-Intercepts: \( h(x) = -2x^2 + 5x + 6 \) (Quadratic Formula)

**Subtitle:** Unit 3 • Lecture 43 • Section 3.6 Example 1B (Workbook p. 83)

### Problem
**Find the x-intercepts of \(h(x) = -2x^2 + 5x + 6\)**

Set \(h(x) = 0\): \(-2x^2 + 5x + 6 = 0\)

Identify: \(a = -2,\; b = 5,\; c = 6\)

$$x = \dfrac{-5 \pm \sqrt{5^2 - 4(-2)(6)}}{2(-2)} = \dfrac{-5 \pm \sqrt{25+48}}{-4}$$

### Solution
$$x = \dfrac{-5 \pm \sqrt{73}}{-4}$$

$$\sqrt{73} \approx 8.54$$

$$x = \dfrac{-5+8.54}{-4} = \dfrac{3.54}{-4} \approx \mathbf{-0.89}$$

$$x = \dfrac{-5-8.54}{-4} = \dfrac{-13.54}{-4} \approx \mathbf{3.39}$$

**x-intercepts:** \(\approx (-0.89,\,0)\) and \(\approx (3.39,\,0)\)

**y-intercept:** \(h(0) = 6\) → \((0,\,6)\)

**Vertex:** \(x = \dfrac{-5}{2(-2)} = \dfrac{5}{4} = 1.25\)
$$h(1.25) = -2(1.5625)+5(1.25)+6 = -3.125+6.25+6 = 9.125$$

**Vertex:** \((1.25,\;9.125)\)

### Key Note
**Sora’s Warning:** With \(a=-2\), dividing by \(-4\) FLIPS the sign direction. \(\dfrac{\text{positive}}{-4}\) gives a negative result!

### Script
[Prof. Park] With a=-2, factoring is difficult. The Quadratic Formula is our best friend here.

[TA Sora] And careful: we’re dividing by -4, which is negative. So positive numerator gives negative answer, and negative numerator gives positive answer. Interesting!

## Slide 4: x-Intercepts: \( f(x) = 4x^2 - 28 \) (Square Root Property)

**Subtitle:** Unit 3 • Lecture 43 • Section 3.6 Example 1C (Workbook p. 83)

### Problem
**Find the x-intercepts of \(f(x) = 4x^2 - 28\)**

Set \(f(x) = 0\):
$$4x^2 - 28 = 0$$

**Method: Square Root Property** (no \(bx\) term!)

**Step 1:** Isolate \(x^2\):
$$4x^2 = 28 \Rightarrow x^2 = 7$$

**Step 2:** Take square root of both sides:

### Solution
$$x = \pm\sqrt{7} \approx \pm 2.646$$

**x-intercepts:** \((-\sqrt{7},\,0)\approx(-2.65,\,0)\) and \((\sqrt{7},\,0)\approx(2.65,\,0)\)

**y-intercept:** \(f(0) = 0-28 = -28\) → \((0,\,-28)\)

**Vertex:** No \(b\) term, so \(x = 0\)
$$f(0) = -28$$

**Vertex:** \((0,\,-28)\) — The vertex is the y-intercept here!

### Key Note
**Sora’s Tip:** No middle term \(bx\)? Use the Square Root Property! It’s much faster than the Quadratic Formula for this form.

### Script
[TA Sora] 4x²-28=0. There’s no x term, just x squared! This is perfect for the Square Root Property.

[Prof. Park] Isolate x² to get x²=7, then x=±√7. Quick and clean.

## Slide 5: x-Intercepts: \( f(x) = x^2 - 15x + 50 \) (Factoring)

**Subtitle:** Unit 3 • Lecture 43 • Section 3.6 Example 1D (Workbook p. 83)

### Problem
**Find the x-intercepts of \(f(x) = x^2 - 15x + 50\)**

Set \(f(x) = 0\):
$$x^2 - 15x + 50 = 0$$

**Method: Factoring** — Find two numbers that:
- **Multiply** to \(+50\)
- **Add** to \(-15\)

Search: \(-5 \times -10 = 50\) and \(-5 + (-10) = -15\) ✓

### Solution
$$(x-5)(x-10) = 0$$

**Zero-Product Property:**
$$x-5 = 0 \Rightarrow x = 5$$
$$x-10 = 0 \Rightarrow x = 10$$

**x-intercepts:** \((5,\,0)\) and \((10,\,0)\)

**y-intercept:** \(f(0) = 50\) → \((0,\,50)\)

**Vertex:** \(x = \dfrac{15}{2} = 7.5\)
$$f(7.5) = 56.25-112.5+50 = -6.25$$

**Vertex:** \((7.5,\,-6.25)\)

### Key Note
**Sora’s Factoring Check:** Always verify: \((x-5)(x-10) = x^2-10x-5x+50 = x^2-15x+50\) ✓

### Script
[Prof. Park] For Example 1D, we look for factors of 50 that add to -15. That’s -5 and -10, giving us (x-5)(x-10).

[TA Sora] And factoring is so clean here! No decimals, no radicals. x=5 and x=10.

## Slide 6: All Features: \( f(x) = -2(x-15)^2 + 50 \)

**Subtitle:** Unit 3 • Lecture 43 • Section 3.6 Example 4 (Workbook p. 85)

### Problem
**Use \(f(x) = -2(x-15)^2 + 50\) to find:**

**A.** x-intercept(s)

**B.** y-intercept

**C.** Vertex

**D.** \(f(20)\)

**Note:** This function is already in **vertex form** \(f(x) = a(x-h)^2 + k\)!

### Solution
**C. Vertex (read directly from vertex form):**
$$h = 15,\; k = 50 \Rightarrow \text{Vertex: } (15,\,50)$$

**B. y-intercept:** \(f(0) = -2(0-15)^2+50 = -2(225)+50 = -450+50 = -400\)
y-intercept: \((0,\,-400)\)

**A. x-intercepts:** Set \(f(x)=0\):
$$-2(x-15)^2+50=0 \Rightarrow (x-15)^2=25 \Rightarrow x-15=\pm 5$$
$$x = 20 \quad \text{or} \quad x = 10$$
x-intercepts: \((10,\,0)\) and \((20,\,0)\)

**D.** \(f(20) = -2(20-15)^2+50 = -2(25)+50 = -50+50 = \mathbf{0}\)
Confirmed: \((20,0)\) is an x-intercept!

### Key Note
**Sora’s Note:** The y-intercept at (0,-400) is FAR below the vertex at (15,50). The parabola is very wide and tall.

### Script
[Prof. Park] Vertex form makes reading the vertex trivial. Just look: h=15, k=50. Vertex at (15,50)!

[TA Sora] And for x-intercepts, we use the Square Root Property on vertex form. (x-15)²=25 gives x-15=±5, so x=20 or x=10. Beautiful!

## Slide 7: Intercept Summary Chart — All Four Methods

**Subtitle:** Unit 3 • Lecture 43 • Section 3.6 Summary (Workbook p. 84–85)

### Problem
**Summary of Finding Intercepts:**

| Method | When to Use | Example |
|---|---|---|
| **Factor GCF** | No constant term \(c\) | \(x^2+6x=0\) |
| **Square Root Property** | No middle term \(b\) | \(4x^2=28\) |
| **Factoring** | Integer roots exist | \(x^2-15x+50=0\) |
| **Quadratic Formula** | Always works! | \(-2x^2+5x+6=0\) |
| **Vertex Form** | Already in \(a(x-h)^2+k\) | \(-2(x-15)^2+50=0\) |

### Solution
**Finding ALL Key Features:**

| Feature | Method |
|---|---|
| **x-intercept(s)** | Set \(f(x)=0\), solve |
| **y-intercept** | Set \(x=0\), evaluate \(f(0)\) |
| **Vertex** | \(x = \dfrac{-b}{2a}\), then plug in OR read from vertex form |

### Key Note
**Sora’s Final Tip:** ALWAYS check the discriminant before solving! If \(\Delta < 0\), skip solving for x-intercepts and write: \textit{No real x-intercepts}.
