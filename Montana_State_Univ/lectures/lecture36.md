## Slide 1: Finding x-Intercepts of Quadratic Functions

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 (Workbook p. 67)

### Problem
### The Goal of Solving Quadratic Equations (Workbook p. 67)
To find the **$x$-intercepts** of any function $f(x)$, we set the output to zero:
$$\mathbf{f(x) = 0 \implies ax^2 + bx + c = 0}$$
- The real solutions to this equation are the **$x$-intercepts** $(x_1, 0)$ and $(x_2, 0)$ of the parabola.
- When the linear term is missing ($b = 0$), the equation looks like **$x^2 = k$**.
- This leads directly to our first algebraic method: **The Square Root Property**!

### Solution
$$\begin{aligned}
\text{To find } y\text{-intercept: } & \text{Evaluate } f(0) = c \implies (0, c) \\
\text{To find } x\text{-intercepts: } & \text{Solve } f(x) = 0 \implies (x_1, 0), \; (x_2, 0)
\end{aligned}$$

### Key Note
**Never confuse the two intercepts:** $y$-intercept is found by plugging in $0$ for $x$. $x$-intercepts are found by setting $f(x) = 0$ and solving for $x$!

### Script
[Prof. Park] Welcome to Section 3.2! In this section, we transition from reading graphs to finding intercepts purely with algebra.

[TA Sora] Finding $x$-intercepts means setting $f(x) = 0$. When there is no middle $x$ term, the Square Root Property is the fastest tool in the shed!

## Slide 2: The Square Root Property (SRP)

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 (Workbook p. 67)

### Problem
### The Square Root Property (Workbook p. 67)
- **If $k > 0$ and $x^2 = k$, then:**
  $$\mathbf{x = \pm \sqrt{k}}$$
  *(Two real solutions: $+\sqrt{k}$ and $-\sqrt{k}$)*
- **If $x^2 = 0$, then:**
  $$\mathbf{x = 0}$$
  *(One real solution)*
- **If $k < 0$ and $x^2 = k$, then:**
  $$\mathbf{\text{No Real Solutions}}$$
  *(The parabola does not cross the $x$-axis!)*

### Solution
$$\begin{aligned}
x^2 = 9 & \implies x = \pm \sqrt{9} = \mathbf{\pm 3} \quad \implies x = 3 \text{ or } x = -3 \\
x^2 = -9 & \implies x = \pm \sqrt{-9} \implies \mathbf{\text{No real number solution}}
\end{aligned}$$

### Key Note
**The Plus-or-Minus Sign is MANDATORY:** When you take the square root of both sides to solve an equation, you MUST write $\pm$! Writing only $x = 3$ misses half of the answers!

### Script
[Prof. Park] Look at $x^2 = 9$. Both $3^2 = 9$ AND $(-3)^2 = 9$. That's why the plus-or-minus sign is mandatory!

[TA Sora] Sora's Rule: Whenever YOU introduce a square root to solve an equation, YOU must write the $\pm$ sign!

## Slide 3: Section 3.2 Example 1: Solving x^2 = 16

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 Example 1 (Workbook p. 67)

### Problem
### Example 1 (Workbook p. 67)
Solve the equation for $x$:
$$\mathbf{x^2 = 16}$$
- Apply the Square Root Property.
- State both solutions and check them.

### Solution
$$\begin{aligned}
x^2 & = 16 \\[0.5em]
x & = \pm \sqrt{16} \\[0.5em]
\mathbf{x} & = \mathbf{\pm 4} \quad \implies \quad \mathbf{x = 4 \quad \text{or} \quad x = -4} \\[0.8em]
\text{Check: } & (4)^2 = 16 \; (\text{True}), \quad (-4)^2 = 16 \; (\text{True})
\end{aligned}$$

### Key Note
**Don't forget the negative root:** $-4$ is just as valid as $+4$. Both satisfy the equation perfectly.

### Script
[Prof. Park] In Example 1, $x^2 = 16 \implies x = \pm \sqrt{16} = \pm 4$.

[TA Sora] Visually, the horizontal line $y = 16$ intersects the parabola $y = x^2$ at $x = -4$ and $x = +4$!

## Slide 4: Section 3.2 Example 2: Solving 2x^2 + 2 = 10

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 Example 2 (Workbook p. 67)

### Problem
### Example 2 (Workbook p. 67)
Solve the equation for $x$:
$$\mathbf{2x^2 + 2 = 10}$$
- Isolate the $x^2$ term first.
- Divide by the coefficient of $x^2$.
- Apply the Square Root Property.

### Solution
$$\begin{aligned}
2x^2 + 2 & = 10 \\[0.5em]
2x^2 & = 8 \quad (\text{subtract } 2) \\[0.5em]
x^2 & = 4 \quad (\text{divide by } 2) \\[0.5em]
x & = \pm \sqrt{4} \\[0.5em]
\mathbf{x} & = \mathbf{\pm 2} \quad \implies \quad \mathbf{x = 2 \quad \text{or} \quad x = -2}
\end{aligned}$$

### Key Note
**Isolate x^2 FIRST:** Do NOT take the square root of $2x^2 + 2$ directly! You must isolate $x^2$ alone before taking square roots!

### Script
[Prof. Park] In Example 2, isolate $x^2$ first. Subtract 2 to get $2x^2 = 8$, then divide by 2 to get $x^2 = 4$.

[TA Sora] Now take square roots: $x = \pm \sqrt{4} = \pm 2$!

## Slide 5: Section 3.2 Example 3: Intercepts & Vertex for f(x) = x^2 - 36

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 Example 3 (Workbook p. 67)

### Problem
### Example 3 (Workbook p. 67)
Find the intercepts and vertex for the function:
$$\mathbf{f(x) = x^2 - 36}$$
- **A. Find the $x$-intercept(s):** __________________________
- **B. Find the $y$-intercept:** __________________________
- **C. Find the vertex:** __________________________

### Solution
$$\begin{aligned}
\textbf{A. x-intercepts: } & \text{Set } f(x) = 0: x^2 - 36 = 0 \implies x^2 = 36 \\
& x = \pm \sqrt{36} = \pm 6 \implies \mathbf{(6, 0) \quad \text{and} \quad (-6, 0)} \\[0.8em]
\textbf{B. y-intercept: } & f(0) = 0^2 - 36 = -36 \implies \mathbf{(0, -36)} \\[0.8em]
\textbf{C. Vertex: } & x_v = -\frac{0}{2(1)} = 0, \; y_v = -36 \implies \mathbf{(0, -36)}
\end{aligned}$$

### Key Note
**Intercept format:** Remember that intercepts are points on a plane: write $(6, 0)$ and $(-6, 0)$, not just $x = \pm 6$!

### Script
[Prof. Park] Setting $x^2 - 36 = 0$ gives $x^2 = 36$, so $x = \pm 6$. The $x$-intercepts are $(6, 0)$ and $(-6, 0)$.

[TA Sora] And $f(0) = -36$, which means the vertex and $y$-intercept are the exact same point $(0, -36)$!

## Slide 6: Section 3.2 Example 4: Intercepts & Vertex for g(x) = 3x^2 - 27

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 Example 4 (Workbook p. 68)

### Problem
### Example 4 (Workbook p. 68)
Find the intercepts and vertex for the function:
$$\mathbf{g(x) = 3x^2 - 27}$$
- **A. Find the $x$-intercept(s):** __________________________
- **B. Find the $y$-intercept:** __________________________
- **C. Find the vertex:** __________________________

### Solution
$$\begin{aligned}
\textbf{A. x-intercepts: } & \text{Set } g(x) = 0: 3x^2 - 27 = 0 \implies 3x^2 = 27 \\
& x^2 = 9 \implies x = \pm \sqrt{9} = \pm 3 \\
& \implies \mathbf{(3, 0) \quad \text{and} \quad (-3, 0)} \\[0.8em]
\textbf{B. y-intercept: } & g(0) = 3(0)^2 - 27 = -27 \implies \mathbf{(0, -27)} \\[0.8em]
\textbf{C. Vertex: } & \mathbf{(0, -27)}
\end{aligned}$$

### Key Note
**Divide before taking square root:** $3x^2 = 27 \implies x^2 = 9$. Don't take square root until the coefficient 3 is cleared!

### Script
[Prof. Park] In Example 4, divide by 3 first: $x^2 = 9$, which gives $x = \pm 3$.

[TA Sora] The $x$-intercepts are $(3, 0)$ and $(-3, 0)$, and the vertex sits at $(0, -27)$!

## Slide 7: When x^2 = k Has No Real Solutions

**Subtitle:** Unit 3 • Lecture 36 • Section 3.2 Negative Radicands

### Problem
### What Happens When $x^2 = -9$?
Solve the equation $x^2 + 9 = 0$:
- $x^2 = -9$
- Can any real number squared equal a negative number?
- What does this look like geometrically on the Cartesian coordinate plane?

### Solution
$$\begin{aligned}
x^2 & = -9 \\[0.5em]
x & = \pm \sqrt{-9} \\[0.5em]
\mathbf{\text{Conclusion: }} & \mathbf{\text{NO REAL NUMBER SOLUTION.}} \\[0.8em]
\text{Geometric Meaning: } & \text{The parabola } f(x) = x^2 + 9 \text{ has vertex at } (0, 9) \\
& \text{and opens UPWARD. It } \mathbf{\text{never crosses the }} x\mathbf{\text{-axis!}}
\end{aligned}$$

### Key Note
**No real solution vs No solution:** In algebra of real numbers, $\sqrt{-9}$ is not real, which means the graph has zero $x$-intercepts!

### Script
[Prof. Park] If you get $x^2 = -9$, stop! In real numbers, squares can never be negative.

[TA Sora] Visually, the parabola sits entirely above the $x$-axis floating in space. It has no $x$-intercepts!
