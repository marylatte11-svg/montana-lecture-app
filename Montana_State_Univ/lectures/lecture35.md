## Slide 1: Section 3.1 Example 3: f(x) = -3(x - 4)^2 + 7

**Subtitle:** Unit 3 • Lecture 35 • Section 3.1 Example 3 (Workbook p. 64)

### Problem
### Example 3 (Workbook p. 64)
For $\mathbf{f(x) = -3(x - 4)^2 + 7}$:
- **A. Find the vertex:** __________________________
- **B. Find the $y$-intercept:** __________________________
- **C. Axis of Symmetry:** __________________________
- **D. Maximum or Minimum Value:** __________________________

### Solution
$$\begin{aligned}
\text{Compare with } a(x - h)^2 + k: & a = -3, \quad h = 4, \quad k = 7 \\[0.5em]
\textbf{A. Vertex: } & \mathbf{(4, 7)} \\[0.5em]
\textbf{B. y-intercept: } & f(0) = -3(0 - 4)^2 + 7 = -3(16) + 7 = -48 + 7 = \mathbf{-41} \implies \mathbf{(0, -41)} \\[0.5em]
\textbf{C. Axis of Symmetry: } & \mathbf{x = 4} \\[0.5em]
\textbf{D. Maximum Value: } & \mathbf{7} \quad (a = -3 < 0 \implies \text{opens down})
\end{aligned}$$

### Key Note
**Inside vs Outside:** $(x - 4)$ means $h = +4$! It flips sign! The outside constant $+7$ keeps its sign: $k = 7$!

### Script
[Prof. Park] In Example 3, we read the vertex directly from vertex form: $(4, 7)$.

[TA Sora] Since $a = -3$ is negative, it opens downward, so the maximum value is 7 at $x = 4$!

## Slide 4: Section 3.1 Example 6: Vertex of f(x) = 2x^2 - 7

**Subtitle:** Unit 3 • Lecture 35 • Section 3.1 Example 6 (Workbook p. 66)

### Problem
### Example 6 (Workbook p. 66)
For $\mathbf{f(x) = 2x^2 - 7}$:
- **A. Find the vertex:** __________________________
- **B. Find the $y$-intercept:** __________________________
- **C. Axis of Symmetry:** __________________________
- **D. Maximum or Minimum Value:** __________________________

### Solution
$$\begin{aligned}
\text{Rewrite as vertex form: } & f(x) = 2(x - 0)^2 - 7 \implies h = 0, \; k = -7 \\[0.5em]
\text{Or use formula: } & x_v = -\frac{0}{2(2)} = 0, \quad y_v = 2(0)^2 - 7 = -7 \\[0.8em]
\textbf{A. Vertex: } & \mathbf{(0, -7)} \\[0.5em]
\textbf{B. y-intercept: } & \mathbf{(0, -7)} \quad (\text{Vertex IS the } y\text{-intercept!}) \\[0.5em]
\textbf{C. Axis of Symmetry: } & \mathbf{x = 0} \quad (\text{the } y\text{-axis}) \\[0.5em]
\textbf{D. Minimum Value: } & \mathbf{-7} \quad (a = 2 > 0 \implies \text{opens up})
\end{aligned}$$

### Key Note
**When b = 0:** The vertex sits directly ON the $y$-axis at $(0, c)$, and the axis of symmetry is the $y$-axis itself ($x = 0$)!

## Slide 5: Section 3.1 Example 7 (Part 1): Comprehensive Graph f(x) = -x^2 - 4x - 5

**Subtitle:** Unit 3 • Lecture 35 • Section 3.1 Example 7A-E (Workbook p. 66)

### Problem
### Example 7 (Workbook p. 66)
Using the graph of the function $\mathbf{f(x) = -x^2 - 4x - 5}$, find:
- **A. $y$-intercept:** ____________
- **B. $x$-intercepts:** ____________
- **C. Vertex:** ____________
- **D. Axis of Symmetry:** ____________
- **E. Maximum value:** ____________

### Solution
$$\begin{aligned}
\textbf{A. y-intercept: } & (0, -5) \\[0.5em]
\textbf{B. x-intercepts: } & \mathbf{\text{None (the graph never crosses the } x\text{-axis!)}} \\[0.5em]
\textbf{C. Vertex: } & x_v = -\frac{-4}{2(-1)} = -2, \; y_v = -(-2)^2 - 4(-2) - 5 = -4 + 8 - 5 = \mathbf{-1} \\
& \implies \mathbf{(-2, -1)} \\[0.5em]
\textbf{D. Axis of Symmetry: } & \mathbf{x = -2} \\[0.5em]
\textbf{E. Maximum Value: } & \mathbf{-1} \quad (\text{at } x = -2)
\end{aligned}$$

### Key Note
**No x-intercepts is common:** When a downward parabola has its vertex below the $x$-axis (here at $y = -1$), it can never touch the $x$-axis! There are NO real $x$-intercepts.

### Script

## Slide 6: Section 3.1 Example 7 (Part 2): Graph Interrogation

**Subtitle:** Unit 3 • Lecture 35 • Section 3.1 Example 7G-J (Workbook p. 66)

### Problem
### Example 7 Function Values (Workbook p. 66)
Using the graph of $f(x) = -x^2 - 4x - 5$:
- **G.** $f(-4) = \text{_____________}$
- **H.** $f(x) = -2 \implies x = \text{_____________}$
- **I.** $f(0) = \text{_____________}$
- **J.** $f(x) = -5 \implies x = \text{_____________}$

### Solution
$$\begin{aligned}
\textbf{G. } f(-4) & = -(-4)^2 - 4(-4) - 5 = -16 + 16 - 5 = \mathbf{-5} \implies (-4, -5) \\[0.5em]
\textbf{H. } f(x) = -2 & \implies \mathbf{x = -1 \quad \text{and} \quad x = -3} \\[0.5em]
\textbf{I. } f(0) & = \mathbf{-5} \implies (0, -5) \\[0.5em]
\textbf{J. } f(x) = -5 & \implies \mathbf{x = 0 \quad \text{and} \quad x = -4} \quad (\text{symmetric pairs!})
\end{aligned}$$

### Key Note
**Two answers for quadratic outputs:** Because of symmetry, solving $f(x) = -5$ gives TWO inputs: $x = 0$ and $x = -4$!

### Script
[Prof. Park] Notice how $f(0) = -5$ and $f(-4) = -5$. Both are at the same height of $-5$.

[TA Sora] That's why solving $f(x) = -5$ gives both $x = 0$ and $x = -4$!

## Slide 7: General Form vs Vertex Form: Summary Matrix

**Subtitle:** Unit 3 • Lecture 35 • Section 3.1 Master Comparison

### Problem
### Choosing Your Method
Compare the two primary forms of quadratic functions:
- **General Form:** $f(x) = ax^2 + bx + c$
  - Best for: $y$-intercept $(0, c)$, factoring, and quadratic formula.
  - Vertex requires calculation: $x = -\frac{b}{2a}$.
- **Vertex Form:** $f(x) = a(x - h)^2 + k$
  - Best for: Reading vertex $(h, k)$ and axis $x = h$ instantly.
  - $y$-intercept requires calculating $f(0)$.

### Solution
$$\begin{array}{|c|c|c|} 
\hline
\textbf{Feature} & \textbf{General: } ax^2 + bx + c & \textbf{Vertex: } a(x-h)^2 + k \\
\hline
\text{Vertex} & \left(-\frac{b}{2a}, \; f\left(-\frac{b}{2a}\right)\right) & \mathbf{(h, k)} \; [\text{Immediate!}] \\
\hline
\text{Axis of Symmetry} & x = -\frac{b}{2a} & \mathbf{x = h} \\
\hline
y\text{-intercept} & \mathbf{(0, c)} \; [\text{Immediate!}] & (0, f(0)) \\
\hline
\text{Direction} & a > 0 \text{ (up)}, \; a < 0 \text{ (down)} & \text{Same } a \\
\hline
\end{array}$$

### Key Note
**Both forms share the exact same 'a':** The coefficient $a$ is identical in both forms! If $a = -2$ in vertex form, $a = -2$ in general form.
