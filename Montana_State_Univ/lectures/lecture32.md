## Slide 1: The Anatomy of a Parabola Graph

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 (Workbook p. 61)

### Problem
### Key Features of Every Parabola (Workbook p. 61)
When analyzing any quadratic graph, identify:
1. **$y$-intercept:** Where the graph crosses the vertical axis $(0, c)$.
2. **$x$-intercepts:** Where the graph crosses the horizontal axis (at most 2).
3. **Vertex $(h, k)$:** The turning point (maximum or minimum).
4. **Axis of Symmetry:** The vertical line cutting through the vertex: $\mathbf{x = h}$.
5. **Domain:** Always $(-\infty, \infty)$.
6. **Range:** Bounded by the vertex: $[k, \infty)$ if opens up, or $(-\infty, k]$ if opens down.

### Solution
$$\begin{aligned}
\text{Vertex: } & (h, k) \\
\text{Axis of Symmetry: } & x = h \quad (\text{vertical line}) \\
\text{Domain: } & (-\infty, \infty) \\
\text{Range: } & [k, \infty) \text{ if } a > 0, \quad (-\infty, k] \text{ if } a < 0
\end{aligned}$$

### Key Note
**Axis of symmetry is an EQUATION:** The axis of symmetry is a line, so you MUST write $\mathbf{x = h}$. Writing just the number $h$ will lose credit on exams!

## Slide 2: Section 3.0 Example 5 (Part 1): Intercepts for f(x) = x^2 - 6x + 5

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 Example 5A, B (Workbook p. 61)

### Problem
### Example 5 (Workbook p. 61)
Using the graph of the function $\mathbf{f(x) = x^2 - 6x + 5}$:
- **A. $y$-intercept:** ____________
- **B. $x$-intercepts:** ____________

### Solution
$$\begin{aligned}
\mathbf{y\text{-intercept: }} & \text{Set } x = 0: f(0) = 0^2 - 6(0) + 5 = 5 \implies \mathbf{(0, 5)} \\[0.8em]
\mathbf{x\text{-intercepts: }} & \text{Set } f(x) = 0: x^2 - 6x + 5 = 0 \\
& (x - 1)(x - 5) = 0 \\
& \mathbf{x = 1 \quad \text{and} \quad x = 5} \implies \mathbf{(1, 0) \quad \text{and} \quad (5, 0)}
\end{aligned}$$

### Key Note
**List both x-intercepts:** Notice the parabola crosses the $x$-axis twice! List both points: $(1, 0)$ and $(5, 0)$.

### Script
[Prof. Park] Looking at the graph of $f(x) = x^2 - 6x + 5$, the curve hits the vertical axis at $(0, 5)$.

[TA Sora] And it crosses the horizontal axis at two spots: $(1, 0)$ and $(5, 0)$!

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 Example 5C, D (Workbook p. 61)

### Problem
### Example 5 Continued (Workbook p. 61)

- **D. Axis of Symmetry:** ____________

### Solution

## Slide 4: Section 3.0 Example 5 (Part 3): Min/Max & Domain/Range

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 Example 5E, F, G (Workbook p. 61)

### Problem
### Example 5 Min/Max & Intervals (Workbook p. 61)
- **E. What is the minimum value of $f(x)$?** ___________
- **F. At what $x$-value does the minimum occur?** ___________
- **G. Domain:** (in interval notation) \quad **Range:** (in interval notation)

### Solution
$$\begin{aligned}
\textbf{E. Minimum Value: } & \mathbf{-4} \quad (\text{the } y\text{-coordinate of the vertex}) \\[0.5em]
\textbf{F. Occurs at: } & \mathbf{x = 3} \quad (\text{the } x\text{-coordinate of the vertex}) \\[0.8em]
\mathbf{\text{Domain: }} & \mathbf{(-\infty, \infty)} \\
\mathbf{\text{Range: }} & \mathbf{[-4, \infty)} \quad (\text{starts at } -4 \text{ and goes up to } +\infty)
\end{aligned}$$

### Key Note
**Value vs Location:** The MINIMUM VALUE is the $y$-value ($-4$). The LOCATION where it occurs is the $x$-value ($3$)!

### Script
[Prof. Park] In math, when we ask 'What is the maximum or minimum value?', we always mean the $y$-value: $-4$.

[TA Sora] And 'at what $x$-value' means the input: $x = 3$. The range starts with a bracket at $-4$: $[-4, \infty)$!

## Slide 5: Section 3.0 Example 6 (Part 1): Vertex Form f(x) = -2(x + 1)^2 + 8

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 Example 6A, B (Workbook p. 61)

### Problem
### Example 6 (Workbook p. 61)
Using the graph of the function $\mathbf{f(x) = -2(x + 1)^2 + 8}$:
- **A. $y$-intercept:** ____________
- **B. $x$-intercepts:** ____________
Notice $a = -2 < 0$, so this parabola opens **downward**!

### Solution
$$\begin{aligned}
\mathbf{y\text{-intercept: }} & f(0) = -2(0 + 1)^2 + 8 = -2(1) + 8 = \mathbf{6} \implies \mathbf{(0, 6)} \\[0.8em]
\mathbf{x\text{-intercepts: }} & 0 = -2(x + 1)^2 + 8 \\
& 2(x + 1)^2 = 8 \implies (x + 1)^2 = 4 \\
& x + 1 = \pm 2 \implies \mathbf{x = 1 \quad \text{and} \quad x = -3} \\
& \implies \mathbf{(1, 0) \quad \text{and} \quad (-3, 0)}
\end{aligned}$$

### Key Note
**Don't assume y-intercept is 8:** In vertex form, the constant $8$ is $k$, NOT the $y$-intercept! Plug in $x = 0$ to get $y = 6$!

### Script
[Prof. Park] In Example 6, the parabola opens downward. Setting $x=0$ gives $y = -2(1) + 8 = 6$.

[TA Sora] And setting $f(x)=0$ gives $x = 1$ and $x = -3$. Both intercepts are marked on the graph!

## Slide 6: Section 3.0 Example 6 (Part 2): Vertex & Axis of Symmetry

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 Example 6C, D (Workbook p. 61)

### Problem
### Example 6 Vertex from Formula (Workbook p. 61)
Compare $\mathbf{f(x) = -2(x + 1)^2 + 8}$ to Vertex Form $\mathbf{f(x) = a(x - h)^2 + k}$:
- **C. Vertex:** ____________ *(Do you see the connection to the function?)*
- **D. Axis of Symmetry:** ____________

### Solution
$$\begin{aligned}
\text{Formula: } & f(x) = a(x - h)^2 + k \\[0.5em]
\text{Identify: } & x + 1 = x - (-1) \implies \mathbf{h = -1} \\
& \mathbf{k = 8} \\[0.8em]
\mathbf{\text{Vertex: }} & \mathbf{(-1, 8)} \\[0.5em]
\mathbf{\text{Axis of Symmetry: }} & \mathbf{x = -1}
\end{aligned}$$

### Key Note
**The sign inside the parentheses flips!** In $(x + 1)^2$, $h = -1$, NOT $+1$! It's always the opposite sign of what's inside!

### Script
[Prof. Park] Look at the vertex: $(-1, 8)$. Notice the function had $(x + 1)^2 + 8$.

[TA Sora] The $x$-coordinate flips sign to $-1$, while the $y$-coordinate keeps its sign as $+8$! That is the secret of vertex form.

## Slide 8: Section 3.0 Example 6 (Part 4): Converting to General Form

**Subtitle:** Unit 3 • Lecture 32 • Section 3.0 Example 6H (Workbook p. 61)

### Problem
### Example 6H: Algebraic Expansion (Workbook p. 61)
Simplify the function $\mathbf{f(x) = -2(x + 1)^2 + 8}$ into **General Form** ($ax^2 + bx + c$):
- FOIL $(x + 1)^2$ first.
- Distribute $-2$.
- Combine like terms.

### Solution
$$\begin{aligned}
f(x) & = -2(x + 1)^2 + 8 \\[0.5em]
& = -2(x^2 + 2x + 1) + 8 \quad (\text{FOIL first!}) \\[0.5em]
& = -2x^2 - 4x - 2 + 8 \quad (\text{distribute } -2) \\[0.5em]
\mathbf{f(x)} & = \mathbf{-2x^2 - 4x + 6}
\end{aligned}$$

### Key Note
**Order of operations:** Square $(x + 1)$ FIRST! Do NOT multiply $-2$ into $(x + 1)$ before squaring!

### Script
[Prof. Park] In 6H, expand $(x + 1)^2 = x^2 + 2x + 1$. Then distribute $-2$: $-2x^2 - 4x - 2 + 8 = -2x^2 - 4x + 6$.

[TA Sora] Notice the constant $+6$ matches our $y$-intercept $(0, 6)$! Both forms confirm each other.
