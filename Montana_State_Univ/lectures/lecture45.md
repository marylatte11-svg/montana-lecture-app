## Slide 2: Domain and Range for All Four Section 3.7 Functions

**Subtitle:** Unit 3 • Lecture 45 • Section 3.7 Domain & Range

### Problem
**State Domain and Range for each function:**

| Function | Opens | Vertex | Domain | Range |
|---|---|---|---|---|
| \(g(x)=x^2+6x+5\) | Up | \((-3,-4)\) | | |
| \(h(x)=-2x^2+4x+6\) | Down | \((1,8)\) | | |
| \(g(x)=2x^2-8x\) | Up | \((2,-8)\) | | |
| \(f(x)=-\frac{1}{2}(x+1)^2+8\) | Down | \((-1,8)\) | | |

### Solution
| Function | Domain | Range |
|---|---|---|
| \(g(x)=x^2+6x+5\) | \((-\infty,\infty)\) | \([-4,\infty)\) |
| \(h(x)=-2x^2+4x+6\) | \((-\infty,\infty)\) | \((-\infty,8]\) |
| \(g(x)=2x^2-8x\) | \((-\infty,\infty)\) | \([-8,\infty)\) |
| \(f(x)=-\frac{1}{2}(x+1)^2+8\) | \((-\infty,\infty)\) | \((-\infty,8]\) |

**Rule:** Domain is ALWAYS \((-\infty,\infty)\) for quadratic functions. Range depends on direction (up/down) and vertex y-value.

### Key Note
**Sora’s Memory Trick:** Opens UP → Range has a minimum \([k, \infty)\). Opens DOWN → Range has a maximum \((-\infty, k]\).

## Slide 3: Full Graph: \( p(x) = x^2 - 4x - 5 \) — 5-Point Method

**Subtitle:** Unit 3 • Lecture 45 • Comprehensive Graphing Practice

### Problem
**Graph \(p(x) = x^2 - 4x - 5\) using the 5-point method:**

**Step 1 — Vertex:**
$$x = \dfrac{-(-4)}{2(1)} = \dfrac{4}{2} = 2$$
$$p(2) = 4-8-5 = -9$$
**Vertex:** \((2,\,-9)\) — Minimum

**Step 2 — y-intercept:**
$$p(0) = -5 \Rightarrow (0,\,-5)$$

### Solution
**Step 3 — x-intercepts:** Set \(p(x)=0\)
$$x^2-4x-5=0 \Rightarrow (x-5)(x+1)=0$$
$$x = 5 \quad \text{or} \quad x=-1$$
**x-intercepts:** \((-1,0)\) and \((5,0)\)

**Step 4 — Symmetric point** of \((0,-5)\):
Axis of symmetry: \(x=2\). Distance from 0 to 2 is 2. Mirror: \(x=4\)
$$p(4) = 16-16-5 = -5 \Rightarrow (4,\,-5)\text{ ✓}$$

**Step 5 — Five key points:**
\((-1,0)\), \((0,-5)\), \((2,-9)\), \((4,-5)\), \((5,0)\)

**Domain:** \((-\infty,\infty)\) \qquad **Range:** \([-9,\infty)\)

### Key Note
**Sora’s Check:** Verify the symmetric point by computing \(p(4)\) directly. It should equal \(p(0) = -5\). ✓ Symmetry confirmed!

### Script
[TA Sora] Five clean steps: vertex, y-intercept, x-intercepts, symmetric point, and done! I have five perfect points to plot.

[Prof. Park] And the symmetric point is a great self-check. If it matches, your axis of symmetry is correct.

## Slide 4: Intersection of \( f(x) = x^2-6x+4 \) and \( g(x) = -2x+25 \)

**Subtitle:** Unit 3 • Lecture 45 • Section 3.7 Example 5F Visual (Workbook p. 89)

### Problem
**Graph both \(f(x) = x^2-6x+4\) (parabola) and \(g(x) = -2x+25\) (line) on the same axes.**

**Parabola \(f(x)\):**
- Vertex: \(x=3\), \(f(3)=9-18+4=-5\) → \((3,-5)\)
- y-intercept: \((0,4)\)
- x-intercepts: \(x^2-6x+4=0\) → \(x=3\pm\sqrt{5}\approx(5.24,0)\) and \((0.76,0)\)

**Line \(g(x)\):**
- y-intercept: \((0,25)\)
- x-intercept: \(-2x+25=0\) → \(x=12.5\)

### Solution
**Intersection (from Lecture 44, Part F):**
$$f(x) = g(x) \Rightarrow x^2-4x-21=0 \Rightarrow (x-7)(x+3)=0$$
$$x = 7 \quad \text{or} \quad x=-3$$

**Intersection points:**
- At \(x=7\): \(g(7) = -14+25 = 11\) → \((7,\,11)\)
- At \(x=-3\): \(g(-3) = 6+25 = 31\) → \((-3,\,31)\)

**Visual:** The line \(g\) crosses the parabola \(f\) at \((-3,31)\) and \((7,11)\). Between these points, the line is above the parabola.

### Key Note
**Sora’s Observation:** Where \(g(x) > f(x)\), the line is above the parabola. Where \(g(x) < f(x)\), the parabola is above the line. The intersection points are the switchover!

### Script
[Prof. Park] When we graph a parabola and a line together, the intersection points are found by setting them equal and solving.

[TA Sora] Two intersection points at (-3,31) and (7,11). This is the graphical meaning of solving f(x)=g(x)!

### Solution
**The Master Decision Tree:**
1. Is it in vertex form \(a(x-h)^2+k\)? → Read vertex directly
2. No \(b\) term? → Square Root Property
3. No \(c\) term? → Factor out GCF

5. Otherwise → **Quadratic Formula** (always works!)

\(\square\) Vertex \(\square\) y-intercept \(\square\) x-intercept(s) \(\square\) Symmetric point \(\square\) Smooth curve

## Slide 7: Challenge: Complete Analysis of \( q(x) = -3x^2 + 12x - 9 \)

**Subtitle:** Unit 3 • Lecture 45 • Final Challenge

### Problem
**Find all features and graph \(q(x) = -3x^2 + 12x - 9\):**

1. Direction of opening
2. Vertex
3. Axis of symmetry
4. y-intercept
5. x-intercept(s) — use best method
6. Domain and Range

### Solution
**1. Direction:** \(a=-3<0\) → Opens **downward** (maximum)

**2. Vertex:** \(x=\dfrac{-12}{2(-3)}=\dfrac{-12}{-6}=2\)
$$q(2)=-3(4)+12(2)-9=-12+24-9=\mathbf{3}$$
**Vertex: \((2,3)\)**

**3. Axis of Symmetry:** \(x=2\)

**4. y-intercept:** \(q(0)=-9\) → \((0,-9)\)

**5. x-intercepts:** Factor out \(-3\):
$$-3x^2+12x-9=0 \Rightarrow x^2-4x+3=0 \Rightarrow (x-1)(x-3)=0$$
$$x=1 \text{ or } x=3$$
**x-intercepts: \((1,0)\) and \((3,0)\)**

**6. Domain:** \((-\infty,\infty)\) \quad **Range:** \((-\infty,3]\)

### Key Note
**Sora’s Shortcut:** Divide by \(-3\) first: \(x^2-4x+3=0\) is much easier to factor than \(-3x^2+12x-9=0\)!

### Script
[Prof. Park] Our final challenge! Everything at once: direction, vertex, intercepts, domain, range.

[TA Sora] Divide by -3 first to simplify. Then x²-4x+3=0 factors to (x-1)(x-3)=0 instantly. This is Unit 3 mastery!
