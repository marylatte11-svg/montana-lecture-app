Basic Graphing Strategy 
When graphing, 𝑥𝑥-coordinates are the input values and 𝑦𝑦-coordinates are the output values. The 
graph is the set of all such (𝑥𝑥, 𝑦𝑦) points. Hence, when graphing, choose 𝑥𝑥-values and use the 
algebraic expression of the equation to calculate corresponding 𝑦𝑦-values. Plot enough points to be 
able to determine the overall shape of the graph.  
Definition:  Solution of an Equation Involving 𝒙𝒙 and 𝒚𝒚 
 
An ordered pair (𝑥𝑥, 𝑦𝑦) is a solution to an equation involving 𝑥𝑥 and 𝑦𝑦 if the equation 
is a true statement when the 𝑥𝑥- and 𝑦𝑦- values of the ordered pair are substituted 
into the equation.

A function is a relation that assigns each element in its domain to exactly one element in its range. 
• One input value cannot correspond to two different output values.
• However, one output value can correspond to multiple input values.
Vertical Line Test 
A set of points in a rectangular coordinate system is the graph of a function if every vertical line 
intersects the graph in at most one point.  
If any vertical line intersects the graph in more than one point, the graph does not represent a 
function.

Function Notation 
The graph of a function is the graph of all its ordered pairs (𝑥𝑥, 𝑦𝑦) or using function 
notation, (𝑥𝑥, 𝑓𝑓(𝑥𝑥)) where 𝑦𝑦 = 𝑓𝑓(𝑥𝑥). 
𝑓𝑓 name of function 
𝑥𝑥 𝑥𝑥-coordinate of the ordered pair (input) 
𝑓𝑓(𝑥𝑥) 𝑦𝑦-coordinate of the ordered pair (output) 
Section 2.5 Function Notation 
Example 1: Consider the linear equation 𝑦𝑦 =4 𝑥𝑥− 5. Find the value of 𝑦𝑦 when 𝑥𝑥 =2 . 
Example 2: Consider the linear function 𝑓𝑓(𝑥𝑥)=4 𝑥𝑥− 5. Find 𝑓𝑓(2). 
Function notation is useful in mathematics for several reasons. 
• It guarantees that the relation in question is a function, which means each element of the
domain corresponds to exactly one element of the range and that its graph passes the
vertical line test.
• It provides a useful naming mechanism when working with multiple functions.
• It yields a convenient shorthand (as in Example 2 above) that shows how the output
depends on the input.
